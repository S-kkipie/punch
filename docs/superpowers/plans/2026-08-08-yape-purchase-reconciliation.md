# Yape Purchase + Reconciliation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend vertical for the Yape purchase flow: dual-attestation purchase orders, server-side EIP-712 signing with custodial wallets, a Postgres-queue relayer, an event indexer feeding projections, and an automatic reconciler that repairs projection drift against the chain.

**Architecture:** New `src/core/purchase` domain (existing `domain/server/client` pattern) exposes the order API. A single separate worker process (`scripts/worker.ts`) runs three loops: relayer (drains `relayer_jobs` rows via `FOR UPDATE SKIP LOCKED`), indexer (`getLogs` from a persisted cursor into projection tables), reconciler (invariant check every minute, auto-repair by reindex). Chain is local anvil; a dev script deploys the 7 contracts and seeds test data.

**Tech Stack:** Next.js/Elysia, drizzle + Postgres, viem, vitest, foundry (anvil/forge), tsx.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-08-yape-purchase-reconciliation-design.md`; mother spec §15, §17, §18.
- Chain: anvil local only. `addresses.ts` for `arbitrumSepolia` stays all-zero.
- Contract facts (do not re-derive): EIP-712 domain `{ name: "PUNCH ConsumptionLog", version: "1" }`; struct `ConsumptionProof(uint256 cafeId,address user,uint256 productId,uint256 amount,bytes32 receiptHash,uint256 nonce,uint256 expiry)`; `MAX_PROOF_TTL = 15 minutes`; `minTicketAmount = 8e6` (mPEN has 6 decimals); `maxDailyPerUserCafe = 3`; nonces are an **unordered** per-café set (`nonceUsed[cafeId][nonce]`), so random 256-bit nonces are correct — do NOT build a sequential counter; `receiptUsed[cafeId][receiptHash]` must be unique per café; anyone may submit `recordConsumption` — the two signatures are the only authorization.
- On-chain getters for reconciliation: `PunchVault.totalLivePunch()`, `PunchVault.balanceOf(user)`, `PlanManager.credits(cafeId)`.
- Events consumed by the indexer: `ConsumptionLog.ConsumptionRecorded(uint256 indexed cafeId, address indexed user, bytes32 indexed receiptHash)`, `PunchVault.PunchIssued(address indexed user, uint256 indexed cafeId)`, `PlanManager.EmissionCreditConsumed(uint256 indexed cafeId)`, `PlanManager.PlanActivated(uint256 indexed cafeId)`, `PlanManager.PackPurchased(uint256 indexed cafeId)`.
- Code style: tabs→4 spaces per biome config; `import "server-only"` at top of server-only modules; `Result`/`AppErrors` pattern from `src/server/common/responses`; routes follow `src/core/cafe/server/api/routes/*.route.ts` shape; run `pnpm check:fix && pnpm typecheck` before every commit.
- Tests live in `__tests__/` folders, run with `pnpm test` (vitest, `src/**/__tests__/**/*.test.ts`). Integration tests that need anvil+Postgres are gated: `describe.skipIf(!process.env.INTEGRATION)` and run with `INTEGRATION=1 pnpm test`.
- All money on chain is mPEN with 6 decimals: `S/1.00 = 1_000_000n`.

```ts
import { sql } from "drizzle-orm";
import {
    bigint, check, index, integer, jsonb, pgEnum, pgTable, text, timestamp,
    uniqueIndex,
} from "drizzle-orm/pg-core";
import { user } from "./auth-schema";
import { cafe, cafeProduct } from "./cafe-schema";

export const purchaseOrderStatus = pgEnum("purchase_order_status", [
    "user_confirmed", "cafe_confirmed", "queued", "submitted",
    "confirmed", "failed", "expired",
]);

export const purchaseOrder = pgTable(
    "purchase_order",
    {
        id: text("id").primaryKey().$defaultFn(() => crypto.randomUUID()),
        cafeId: text("cafe_id").notNull()
            .references(() => cafe.id, { onDelete: "restrict" }),
        userId: text("user_id").notNull()
            .references(() => user.id, { onDelete: "restrict" }),
        productId: text("product_id").notNull()
            .references(() => cafeProduct.id, { onDelete: "restrict" }),
        // mPEN, 6 decimals, stored as string-safe bigint
        amount: bigint("amount", { mode: "bigint" }).notNull(),
        yapeRef: text("yape_ref").notNull(),
        receiptHash: text("receipt_hash").notNull(),
        nonce: text("nonce").notNull(), // random uint256 as decimal string
        expiry: timestamp("expiry").notNull(),
        status: purchaseOrderStatus("status")
            .default("user_confirmed").notNull(),
        failureReason: text("failure_reason"),
        txHash: text("tx_hash"),
        createdAt: timestamp("created_at").defaultNow().notNull(),
        updatedAt: timestamp("updated_at").defaultNow()
            .$onUpdate(() => new Date()).notNull(),
    },
    (t) => [
        index("purchase_order_cafe_status_idx").on(t.cafeId, t.status),
        index("purchase_order_user_idx").on(t.userId),
        uniqueIndex("purchase_order_cafe_receipt_uq")

        check("purchase_order_amount_positive", sql`${t.amount} > 0`),

);

    "pending", "submitted", "confirmed", "failed",

        txHash: text("tx_hash"),
        lastError: text("last_error"),
        createdAt: timestamp("created_at").defaultNow().notNull(),
        updatedAt: timestamp("updated_at").defaultNow()

export type RelayerJobRow = typeof relayerJob.$inferSelect;
```

```ts
import type { PurchaseOrderStatus } from "./types";

const edges: Record<PurchaseOrderStatus, PurchaseOrderStatus[]> = {
    user_confirmed: ["cafe_confirmed", "expired"],
    cafe_confirmed: ["queued", "expired"],
    queued: ["submitted", "failed", "confirmed"],
```

```ts
export const createPurchaseSchema = z.object({
    cafeId: z.string().min(1),
    productId: z.string().min(1),
    amountSoles: z.number().positive(),
    yapeRef: z.string().min(4).max(120),

export function solesToMpen(amountSoles: number): bigint {
    if (amountSoles <= 0) throw new Error("amount must be positive");
    const centavos = Math.round(amountSoles * 100);
    if (Math.abs(amountSoles * 100 - centavos) > 1e-6) {
        throw new Error("amount has more than 2 decimals");
    }
    return BigInt(centavos) * 10_000n;
}
```

```ts
import "server-only";
import { keccak256, toBytes } from "viem";
import { chainForEnv } from "@/core/chain/chain";
import { getAddresses } from "@/core/chain/addresses";
import { deriveUserAccount } from "@/core/chain/server/wallet/derive";

export type ConsumptionProof = {
    cafeId: bigint;
    user: `0x${string}`;
    productId: bigint;
    amount: bigint;
    receiptHash: `0x${string}`;
    nonce: bigint;
    expiry: bigint;
};

const PROOF_TYPES = {
    ConsumptionProof: [
        { name: "cafeId", type: "uint256" },
        { name: "user", type: "address" },
        { name: "productId", type: "uint256" },
        { name: "amount", type: "uint256" },
        { name: "receiptHash", type: "bytes32" },
        { name: "nonce", type: "uint256" },
        { name: "expiry", type: "uint256" },
    ],
} as const;

export function buildReceiptHash(
    orderId: string,
    yapeRef: string,
): `0x${string}` {
    return keccak256(toBytes(`${orderId}:${yapeRef}`));
}

export function randomNonce(): bigint {
    const bytes = crypto.getRandomValues(new Uint8Array(32));
    return BigInt(
        `0x${Array.from(bytes, (b) => b.toString(16).padStart(2, "0")).join("")}`,
    );
}

export function proofTypedData(proof: ConsumptionProof) {
    return {
        domain: {
            name: "PUNCH ConsumptionLog",
            version: "1",
            chainId: chainForEnv().id,
            verifyingContract: getAddresses().consumptionLog,
        },
        types: PROOF_TYPES,
        primaryType: "ConsumptionProof",
        message: proof,
    } as const;
}

export async function signProofAs(
    walletIndex: number,
    proof: ConsumptionProof,
): Promise<`0x${string}`> {
    return deriveUserAccount(walletIndex).signTypedData(proofTypedData(proof));
}

export function serializeProof(proof: ConsumptionProof) {
    return {
        cafeId: proof.cafeId.toString(),
        user: proof.user,
        productId: proof.productId.toString(),
        amount: proof.amount.toString(),
        receiptHash: proof.receiptHash,
        nonce: proof.nonce.toString(),
        expiry: proof.expiry.toString(),
    };
}

export function deserializeProof(
    raw: ReturnType<typeof serializeProof>,
): ConsumptionProof {
    return {
        cafeId: BigInt(raw.cafeId),
        user: raw.user,
        productId: BigInt(raw.productId),
        amount: BigInt(raw.amount),
        receiptHash: raw.receiptHash,
        nonce: BigInt(raw.nonce),
        expiry: BigInt(raw.expiry),
    };
```

```ts
// core shape of one drain pass
export async function runRelayerOnce(deps = defaultDeps()) {
    const jobs = await deps.findJobsToRun(10);
    for (const job of jobs) {
        const { proof, cafeSignature, userSignature } = job.payload;
        try {
            const hash = await deps.wallet.writeContract({
                address: deps.addresses.consumptionLog,
                abi: abis.consumptionLog,
                functionName: "recordConsumption",
                args: [deserializeProof(proof), cafeSignature, userSignature],
                account: deps.submitter,
            });
            await deps.markJobSubmitted(job.id, hash);
            await deps.setOrderStatus(job.orderId, "submitted", { txHash: hash });
            const receipt = await deps.pub.waitForTransactionReceipt({ hash });
            if (receipt.status === "success") {
                await deps.markJobConfirmed(job.id);
                await deps.setOrderStatus(job.orderId, "confirmed");
            } else {
                await handleFailure(deps, job, new Error("tx reverted"));
            }
        } catch (error) {
            await handleFailure(deps, job, error);
        }
    }
}
```

`handleFailure` applies the retry policy above via `parseRevert`.

```ts
// scripts/worker.ts (core pattern)
function loop(name: string, ms: number, fn: () => Promise<unknown>) {
    let running = false;
    const timer = setInterval(async () => {
        if (running) return;
        running = true;
        try {
            await fn();
        } catch (error) {
            logger.error(`${name} tick failed`, { error });
        } finally {
            running = false;
        }
    }, ms);
    return () => clearInterval(timer);
}

await recoverStuckJobs();
const stops = [
    loop("relayer", 2_000, runRelayerOnce),
    loop("indexer", 2_000, runIndexerOnce),
    loop("expiry", 30_000, expirePurchasesService),
    loop("reconciler", 60_000, runReconcilerOnce),
];
process.on("SIGINT", () => { for (const stop of stops) stop(); process.exit(0); });
```
